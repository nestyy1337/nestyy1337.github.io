I'm Szymon Głuch, a software engineer based in Warsaw. I work with Rust and write libraries for problems I run into at work.

Two of those projects are [serde_rison](https://github.com/nestyy1337/serde_rison), a Serde implementation for the RISON format, and [sdp-request-client](https://github.com/nestyy1337/sdp-request-client), an async client for the ManageEngine ServiceDesk Plus API.

## What interests me

Rust's type system, async programming, and the work that makes new language features possible. I want to understand what happened to a proposal after the initial discussion, what is still blocking it, and how those decisions affect code people can write.

This site is a place for those notes and for writing about the software I build.
